# Jyoshna Rayadurgam — Frontend Developer Portfolio

A responsive portfolio built with React, TypeScript, and Vite. It highlights selected website projects, professional frontend experience, and scoped case studies for team-built applications.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production build is generated in `dist/` and can be deployed to Vercel or another static hosting provider.

## Project attribution

Project cards describe individual contributions. PastryChef ERP and ETC Mentors were developed as team projects; the case studies describe frontend work only and do not claim sole ownership of either full application. Illustrative previews are labelled where actual product screenshots cannot be shared.
